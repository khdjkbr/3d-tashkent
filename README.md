# 3D Ташкент

Лёгкий статический прототип 3D-карты Ташкента.

## Текущий статус

Это первый каркас интерфейса. В нём уже есть карта, рельеф, 3D-экструзия зданий, панель слоёв и кликабельный объект. Здания пока демонстрационные и не являются реальной выгрузкой города.

## Следующий шаг

Добавить обработчик данных OpenStreetMap и подготовку vector tiles для зданий, дорог, переходов, светофоров, воды и зелёных зон. Сырые DEM-файлы не следует коммитить в репозиторий; в GitHub храним код и скрипты обработки.

## Источники

- MapLibre GL JS: https://maplibre.org/maplibre-gl-js/docs/
